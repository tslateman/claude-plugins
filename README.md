# tslateman/claude-plugins

Plugins for AI-assisted development — orchestration, quality, context, and tooling.

## Install

Add the marketplace:

```
/plugin marketplace add https://github.com/tslateman/claude-plugins
```

Install a plugin:

```
/plugin install duet@tslateman
```
